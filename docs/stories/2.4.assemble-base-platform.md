# Story 2.4: Assemble Base Platform

## Status: In Progress

## Story

**As a** builder,
**I want** base platform assembled with motors, battery, and electronics,
**so that** I have a functional mobile base.

2. Battery mounted securely with access to charge port
3. ODrive and ESP32 mounted to platform
4. Power distribution wired and tested
5. All connections secure with proper cable management
6. Assembly documented in `modules/base/assembly.md`

## Dev Notes

### Platform Design

The base uses a skateboard deck as the structural platform with hoverboard trucks/wheels providing the two-wheel configuration needed for self-balancing. This is a hardware assembly story — no firmware or software work.

### Existing Hardware (from Stories 2.1-2.3)

- 2× hoverboard BLDC motors (~350W each, 6.5" wheels) — extracted in Story 2.1
- 36V battery pack — extracted and tested in Story 2.1
- ESP32 breadboard with BNO085 IMU — validated in Story 2.2
- ODrive v3.6 — tested with motors in Story 2.2
- Power distribution design — completed in Story 2.3

### ESP32 Board

**ESP32-S3-DevKitC-1 (N16R8)** — same board type as the Head module. Dual-core Xtensa LX7 @ 240MHz, 16MB flash, 8MB PSRAM.

### Pin Assignments (from platformio.ini / wiring.md)

| Function | GPIO | Notes |
|----------|------|-------|
| IMU SDA (I2C0 Master) | 4 | BNO085 + OLED shared bus |
| IMU SCL (I2C0 Master) | 5 | BNO085 + OLED shared bus |
| BNO085 INT | 6 | Data-ready interrupt (active low) |
| BNO085 RST | 7 | Hardware reset (active low, pulled high) |
| Pi SDA (I2C1 Slave) | 21 | J3 right header |
| Pi SCL (I2C1 Slave) | 47 | J3 right header |
| ODrive TX | 39 | J3 right header |
| ODrive RX | 38 | J3 right header |

### Power Architecture (from Story 2.3)

| Rail | Source | Loads |
|------|--------|-------|
| 36V direct | Battery | ODrive + BLDC motors |
| 12V | 36V→12V buck | Servo power via Waveshare adapters (neck, ears) |
| 5V | 36V→5V buck | ESP32 (Head, Base), OLED eyes |

### Safety

- Fuse between battery and ODrive (rated for motor stall current)
- Emergency stop switch cuts battery power
- Low-voltage cutoff at ~30V (prevents battery damage)

### File Locations

- Assembly guide: `modules/base/assembly.md`
- Wiring reference: `modules/base/wiring.md`
- README: `modules/base/README.md`

### Testing

This is a hardware assembly story. Testing is manual verification:
- Visual inspection of all connections
- Multimeter measurements of voltage rails
- Serial monitor confirmation of ESP32 + IMU boot
- ODrive power-on verification

No automated tests required.
