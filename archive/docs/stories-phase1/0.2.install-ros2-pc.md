# Story 0.2: Install ROS2 Jazzy on Development PC

## Status: Draft

## Story

**As a** builder,
**I want** ROS2 Jazzy installed on my development PC,
**so that** I can interact with robot topics, run visualization tools, and develop ROS2 code locally.

## Acceptance Criteria

1. Ubuntu 24.04 LTS (or compatible) running on development PC
2. ROS2 Jazzy Jalisco installed via apt
3. Core ROS2 packages verified (`ros-jazzy-desktop` recommended for full tooling)
4. Visualization tools working: `rviz2`, `rqt`, `rqt_graph`
5. ROS2 environment sourced in `~/.bashrc`
6. Basic ROS2 commands work: `ros2 topic list`, `ros2 node list`

## Tasks / Subtasks

- [ ] Task 1: Verify/Install Ubuntu 24.04 on PC (AC: 1)
  - [ ] Check Ubuntu version: `lsb_release -a`
  - [ ] If not 24.04, upgrade or dual-boot (ROS2 Jazzy requires 24.04)
- [ ] Task 2: Install ROS2 Jazzy (AC: 2, 3)
  - [ ] Add ROS2 apt repository and GPG key
  - [ ] Run `sudo apt update`
  - [ ] Install `ros-jazzy-desktop` (includes rviz2, rqt, demos)
  - [ ] Verify with `ros2 --version`
- [ ] Task 3: Initialize rosdep (AC: 2)
  - [ ] Run `sudo rosdep init` (skip if already done)
  - [ ] Run `rosdep update`
- [ ] Task 4: Configure environment (AC: 5, 6)
  - [ ] Add `source /opt/ros/jazzy/setup.bash` to `~/.bashrc`
  - [ ] Source bashrc: `source ~/.bashrc`
  - [ ] Verify `ros2 topic list` works
- [ ] Task 5: Test visualization tools (AC: 4)
  - [ ] Run `rviz2` - should open GUI
  - [ ] Run `rqt` - should open GUI
  - [ ] Run `rqt_graph` - should open graph viewer

## Dev Notes

### Why ROS2 on PC?
- Send commands to Pi via `ros2 topic pub`
- Monitor robot state via `ros2 topic echo`
- Visualize with `rviz2` (better on PC than Pi)
- Debug node graph with `rqt_graph`
- Edit and test code before pushing to Pi

### Installation Resource
- ROS2 Jazzy: https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html

### Testing

- **Test**: `ros2 topic list` returns without error
- **Test**: `rviz2` opens visualization window
- **Test**: `rqt_graph` opens node graph window
