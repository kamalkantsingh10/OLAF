## Dev Notes

### Assembly Order

1. **Pre-assembly check** - Verify all parts and tools
2. **Servo preparation** - Verify IDs, test individually
3. **Left ear assembly** - Base servo → adapter → angle servo → ear shape
4. **Right ear assembly** - Mirror of left
5. **Range testing** - Manual then powered
6. **Symmetry calibration** - Adjust offsets
7. **Head mounting** - Attach to enclosure
8. **Final test** - Full expression preset test

- Small Phillips screwdriver (#0 or #1)
- Needle-nose pliers

### Calibration Procedure

If ears are not symmetric:
1. Move both ears to neutral (512)
2. Measure visual offset
3. Adjust individual servo offsets in software
4. Store offsets in configuration file

```python
# Example offset configuration
EAR_OFFSETS = {
    1: 0,    # Left base (reference)
    2: 0,    # Left angle
    3: -5,   # Right base (adjusted for symmetry)
    4: 3,    # Right angle (adjusted for symmetry)
}
```

### Troubleshooting

**Servo not responding:**
- Verify ID is correct (use ping test)
- Check cable connections
- Verify power is adequate (6V recommended)

**Jerky motion:**
- Reduce speed parameter in write command
- Check for mechanical binding
- Verify servo is not overloaded

**Asymmetric movement:**
- Apply software offset correction
- Check if servo horns are installed at same angle
- Verify mounting is identical on both sides
