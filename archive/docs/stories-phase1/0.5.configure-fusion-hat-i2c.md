# Story 0.5: Configure Fusion HAT and I2C on Pi

## Status: Draft

## Story

**As a** builder,
**I want** Fusion HAT+ configured and I2C communication testable on the Pi,
**so that** I can validate ESP32 module connectivity.

## Acceptance Criteria

1. Fusion HAT+ physically installed on Pi 5 GPIO header
2. I2C interface enabled via `raspi-config` or config.txt
3. Python `smbus2` library installed
4. I2C tools installed and working (`i2cdetect`)
5. I2C bus scan works: `i2cdetect -y 1` runs without errors
6. Fusion HAT SDK/libraries installed for WS2812 and PWM control
7. Module I2C addresses documented (0x10=Head, 0x11=Base)

## Tasks / Subtasks

- [ ] Task 1: Install Fusion HAT+ hardware (AC: 1)
  - [ ] Power off Pi 5
  - [ ] Mount Fusion HAT+ on GPIO header (align pins carefully)
  - [ ] Power on and verify Pi boots normally
- [ ] Task 2: Enable I2C interface (AC: 2)
  - [ ] Run `sudo raspi-config` → Interface Options → I2C → Enable
  - [ ] OR add `dtparam=i2c_arm=on` to `/boot/firmware/config.txt`
  - [ ] Reboot Pi
- [ ] Task 3: Install I2C tools and libraries (AC: 3, 4)
  - [ ] Run `sudo apt install i2c-tools python3-smbus`
  - [ ] Run `pip install smbus2`
  - [ ] Add user to i2c group: `sudo usermod -aG i2c $USER`
  - [ ] Log out and back in for group to take effect
- [ ] Task 4: Test I2C bus (AC: 5)
  - [ ] Run `i2cdetect -y 1`
  - [ ] Verify no errors (empty table OK - ESP32s not connected yet)
  - [ ] Note any existing devices (HAT may have onboard I2C chips)
- [ ] Task 5: Install Fusion HAT SDK (AC: 6)
  - [ ] Follow Sunfounder Fusion HAT+ documentation
  - [ ] Install required libraries: `pip install sunfounder-controller` (or equivalent)
  - [ ] Test WS2812 control with sample script (if LEDs connected)
  - [ ] Test PWM output with sample script
- [ ] Task 6: Document I2C configuration (AC: 7)
  - [ ] Update `docs/guides/i2c-setup.md` with:
    - Head ESP32 = 0x10
    - Base ESP32 = 0x11
    - Any Fusion HAT onboard addresses

## Dev Notes

### I2C Communication (from PRD)
| Interface | Connection | Speed | Latency |
|-----------|-----------|-------|---------|
| I2C | Pi ↔ Head ESP32 (0x10) | 400kHz-1MHz | 5-20ms |
| I2C | Pi ↔ Base ESP32 (0x11) | 400kHz-1MHz | 5-20ms |

### Module I2C Address Map
| Module | Address | Purpose |
|--------|---------|---------|
| Head | `0x10` | Eye animations, expressions |
| Base | `0x11` | Balancing PID, motor control |

### Fusion HAT+ Features Used
- **WS2812 port**: 24× indicator LEDs (3×8 strips)
- **PWM channels**: Kickstand servos (2×)
- **I2C**: Bridge to ESP32 modules
- **I2S**: Audio output (future)

### Tech Stack Reference
- **I2C Library (Pi)**: `smbus2` 0.4.x
- **HAT Platform**: Sunfounder Fusion HAT+

### Testing

- **Test**: `i2cdetect -y 1` runs without permission errors
- **Test**: Python `import smbus2` succeeds
- **Test**: Fusion HAT LED test script works (when wired)
