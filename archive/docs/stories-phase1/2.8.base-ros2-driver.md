# Story 2.8: Create Base ROS2 Driver Node

## Status: Draft

## Story

**As a** builder,
**I want** a ROS2 driver node for Base module,
**so that** I can control balancing and navigation via ROS2.

## Acceptance Criteria

1. Python ROS2 node created in `ros2/src/olaf_drivers/base_driver/`
2. Node subscribes to `/cmd_vel` (geometry_msgs/Twist)
3. Node publishes `/odom` and `/olaf/base/status`
4. I2C communication to address 0x0B
5. Node launches and responds to velocity commands

### I2C Register Map (Base ESP32 at 0x0B — from `i2c_slave.h`)

| Address | Name | R/W | Type | Description |
|---------|------|-----|------|-------------|
| 0x00 | STATUS | R | uint8 bitfield | Bit 0=BALANCING, Bit 1=MOTORS_ENABLED, Bit 7=ERROR |
| 0x01 | COMMAND | W | uint8 | 0x01=ENABLE_BALANCE, 0x02=DISABLE, 0x03=RESET, 0x04=CALIBRATE_IMU |
| 0x10 | LINEAR_VEL | W | float32 (4 bytes) | Target linear velocity (m/s) |
| 0x11 | ANGULAR_VEL | W | float32 (4 bytes) | Target angular velocity (rad/s) |
| 0x20 | ODOM_X | R | float32 (4 bytes) | Odometry X position (meters) |
| 0x21 | ODOM_Y | R | float32 (4 bytes) | Odometry Y position (meters) |
| 0x22 | ODOM_THETA | R | float32 (4 bytes) | Odometry heading (radians) |
| 0x30 | PITCH | R | float32 (4 bytes) | Current pitch angle (degrees) |
| 0x31 | BATTERY_VOLTAGE | R | float32 (4 bytes) | Battery voltage (volts) |

**Important:** All float32 values are transmitted as 4 raw bytes in little-endian IEEE 754 format. Use `struct.pack('<f', value)` / `struct.unpack('<f', bytes)` in Python. The ESP32 firmware handles differential drive splitting internally — the Pi sends linear/angular velocity directly, NOT per-wheel velocities.

### I2C Float32 Read/Write Pattern

```python
import struct
from smbus2 import SMBus, i2c_msg

I2C_ADDR = 0x0B

def write_float(bus: SMBus, reg: int, value: float) -> None:
    """Write a float32 to an I2C register (4 bytes, little-endian)."""
    data = struct.pack('<f', value)
    msg = i2c_msg.write(I2C_ADDR, bytes([reg]) + data)
    bus.i2c_rdwr(msg)

def read_float(bus: SMBus, reg: int) -> float:
    """Read a float32 from an I2C register (4 bytes, little-endian)."""
    write_msg = i2c_msg.write(I2C_ADDR, bytes([reg]))
    read_msg = i2c_msg.read(I2C_ADDR, 4)
    bus.i2c_rdwr(write_msg, read_msg)
    return struct.unpack('<f', bytes(read_msg))[0]
```

### Coding Standards

From `docs/architecture/coding-standards.md`:
- **Python:** PEP 8, max 100 chars, type hints required for public functions
- **Naming:** snake_case for functions/variables, PascalCase for classes
- **Imports:** stdlib → third-party → ROS2 → local
- **Docstrings:** Google style, required for public classes/functions
- **Error handling:** Catch specific exceptions, log with context via ROS2 logger
- **ROS2 node naming:** `<module>_<function>_node` under `/olaf/` namespace
- **ROS2 topics:** `/<namespace>/<module>/<data_type>`

### Pattern Reference: Head ROS2 Driver (Story 1.4)

The head driver node (`head_i2c_client.py`) provides the I2C communication pattern:
- Uses `smbus2.SMBus` for I2C with `i2c_msg` for multi-byte transfers
- Register-based read/write with float32 byte packing
- Translates ROS2 messages to I2C register writes
- Publishes status at regular interval
- Graceful shutdown on node stop
