# Story 1.4: Create Head ROS2 Driver Node

## Status: Ready for Dev

## Story

**As a** builder,
**I want** a ROS2 driver node that translates ROS2 topics into I2C commands for Head module,
**so that** I can control the eyes using standard ROS2 pub/sub.

## Acceptance Criteria

1. Python ROS2 node created in `ros2/src/olaf_head/`
2. Node subscribes to topics: `/head/expression`, `/head/blink`, `/head/look`, `/head/status`
3. I2C communication implemented using `smbus2` library
4. ROS2 messages translated to I2C register writes to address 0x08
5. Node launches successfully and appears in `ros2 node list`
6. Manual topic publish triggers expected hardware response

```
├── setup.py
└── setup.cfg
```

### ROS2 Topics

| Topic | Message Type | Description |
|-------|--------------|-------------|
| `/head/expression` | std_msgs/String | Expression name: "neutral", "happy", "sad", "surprised", "angry", "sleepy", "wink" |
| `/head/blink` | std_msgs/Bool | True triggers blink animation |
| `/head/look` | geometry_msgs/Point | x=-100..100 (left/right), y=-100..100 (down/up), z ignored |
| `/head/status` | std_msgs/String | System status: "idle", "woke_up", "listening", "processing", "speaking", "going_idle" |

### Expression String to I2C Mapping

| Expression String | I2C Register 0x10 Value |
|-------------------|-------------------------|
| "neutral" | 0 |
| "happy" | 1 |
| "sad" | 2 |
| "surprised" | 3 |
| "angry" | 4 |
| "sleepy" | 5 |
| "wink" | 6 |

### I2C Register Map (from Story 1.3)

| Address | Name | R/W | Description |
|---------|------|-----|-------------|
| 0x00 | STATUS | R | 0=OK, 1=ERROR |
| 0x10 | EXPRESSION_TYPE | W | 0-6 (expression enum) |
| 0x11 | EXPRESSION_INTENSITY | W | 1-5 |
| 0x12 | BLINK_TRIGGER | W | Write 1 to trigger |
| 0x20 | LOOK_X | W | Signed: -100 to +100 |
| 0x21 | LOOK_Y | W | Signed: -100 to +100 |
| 0x30 | SYSTEM_STATUS | W | 0=IDLE, 1=WOKE_UP, 2=LISTENING, 3=PROCESSING, 4=SPEAKING, 5=GOING_IDLE |

### Dependencies

**Python packages:**
- `rclpy` - ROS2 Python client library
- `smbus2` - I2C communication (install: `pip install smbus2`)
- `std_msgs` - Standard ROS2 messages
- `geometry_msgs` - Point message for look direction

**package.xml dependencies:**
```xml
<depend>rclpy</depend>
<depend>std_msgs</depend>
<depend>geometry_msgs</depend>
```

### Coding Standards (Python)

- **Style:** PEP 8 with 100 char line length
- **Type hints:** Required for all public functions
- **Docstrings:** Google style
- **Naming:**
  - Classes: `PascalCase` (e.g., `HeadDriverNode`)
  - Functions/methods: `snake_case` (e.g., `set_expression()`)
  - Constants: `UPPER_SNAKE_CASE` (e.g., `I2C_HEAD_ADDRESS`)
- **Logging:** Use ROS2 logger (`self.get_logger()`)
- **Error handling:** Catch specific exceptions, log with context

### Testing

**Test Location:** `ros2/src/olaf_head/test/`

**Framework:** pytest with ROS2 launch_testing

**Required Tests:**

```bash
# Verify eyes respond on hardware
```
