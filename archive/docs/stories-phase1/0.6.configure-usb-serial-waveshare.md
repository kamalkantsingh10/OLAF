# Story 0.6: Configure USB Serial for Waveshare Adapters

## Status: Draft

## Story

**As a** builder,
**I want** USB serial communication configured for Waveshare Bus Servo Adapters on the Pi,
**so that** I can control neck and ear servos.

## Acceptance Criteria

1. Both Waveshare Bus Servo Adapter (A) units connected via USB to Pi
2. USB devices appear as `/dev/ttyUSB*` or `/dev/ttyACM*`
3. Python `pyserial` library installed
4. udev rules created for persistent device naming (`/dev/waveshare_neck`, `/dev/waveshare_ears`)
5. Test script can communicate with Feetech servos (ping, read position)
6. USB permissions configured for non-root access

## Tasks / Subtasks

- [ ] Task 1: Connect Waveshare adapters (AC: 1, 2)
  - [ ] Connect first Waveshare Bus Servo Adapter (A) via USB (for neck)
  - [ ] Connect second Waveshare Bus Servo Adapter (A) via USB (for ears)
  - [ ] Verify devices appear: `ls /dev/ttyUSB*` or `ls /dev/ttyACM*`
  - [ ] Get device info: `udevadm info -a /dev/ttyUSB0 | grep -E "idVendor|idProduct|serial"`
- [ ] Task 2: Install pyserial (AC: 3)
  - [ ] Run `pip install pyserial`
  - [ ] Verify: `python3 -c "import serial; print(serial.__version__)"`
- [ ] Task 3: Configure USB permissions (AC: 6)
  - [ ] Add user to dialout group: `sudo usermod -aG dialout $USER`
  - [ ] Log out and back in
  - [ ] Verify access without sudo
- [ ] Task 4: Create udev rules for persistent naming (AC: 4)
  - [ ] Create `/etc/udev/rules.d/99-waveshare-servos.rules`
  - [ ] Add rules based on device attributes:
    ```
    SUBSYSTEM=="tty", ATTRS{idVendor}=="XXXX", ATTRS{serial}=="...", SYMLINK+="waveshare_neck", MODE="0666"
    SUBSYSTEM=="tty", ATTRS{idVendor}=="XXXX", ATTRS{serial}=="...", SYMLINK+="waveshare_ears", MODE="0666"
    ```
  - [ ] Reload rules: `sudo udevadm control --reload-rules && sudo udevadm trigger`
  - [ ] Verify symlinks: `ls -la /dev/waveshare_*`
- [ ] Task 5: Create and run test script (AC: 5)
  - [ ] Create `tools/diagnostics/test_waveshare_servo.py`
  - [ ] Implement Feetech servo ping command
  - [ ] Test reading servo position (when servos connected)
  - [ ] Document working configuration

## Dev Notes

### USB Serial Communication (from PRD)
| Interface | Connection | Speed | Latency |
|-----------|-----------|-------|---------|
| USB Serial | Pi ↔ Waveshare Neck | UART | <10ms |
| USB Serial | Pi ↔ Waveshare Ears | UART | <10ms |

### Servo Configuration
| Adapter | Servos | Protocol |
|---------|--------|----------|
| Neck | 3× Feetech STS3215 | Serial bus, IDs 1-3 |
| Ears | 4× Feetech SCS0009 | Serial bus, IDs 1-4 |

### Feetech Servo Protocol
- Baud rate: 1000000 (1Mbps) default for STS series
- Half-duplex UART
- Packet format: `0xFF 0xFF ID LEN CMD PARAMS... CHECKSUM`

### udev Rule Tips
- Use `udevadm info -a /dev/ttyUSB0` to find unique attributes
- If both adapters have same vendor/product, use:
  - `KERNELS` (USB port path) - e.g., `KERNELS=="1-1.2"`
  - Or `ATTRS{serial}` if adapters have unique serials

### Testing

- **Test**: `ls /dev/waveshare_*` shows both symlinks
- **Test**: Python can open serial port without sudo
- **Test**: Servo ping returns valid response (when servos connected)
