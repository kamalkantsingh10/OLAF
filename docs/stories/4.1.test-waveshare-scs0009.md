## Dev Notes

### Hardware Configuration

**Waveshare Bus Servo Adapter (A):**
- USB mode (not standalone mode)
- Device: `/dev/waveshare_ears` (symlink created in Story 0.6)
- Power input: 5V DC (from 36V→5V buck converter)

**Feetech SCS0009 Servos:**
- Quantity: 4× (2 per ear)
- Protocol: SCS (Serial Control System) - half-duplex UART
- Baud rate: 1000000 (1Mbps) default
- Position range: 0-1023 (10-bit)
- Voltage: 4.8-7.4V (using 5V - minimal load on ears)
- Torque: 1.6 kg·cm @ 6V

**Servo ID Assignments:**
| ID | Location | Function |
|----|----------|----------|
| 1 | Left ear | Base rotation |
| 2 | Left ear | Ear angle |
| 3 | Right ear | Base rotation |
| 4 | Right ear | Ear angle |

### Feetech SCS Protocol

**Packet format:** `0xFF 0xFF ID LENGTH INSTRUCTION PARAMS... CHECKSUM`

**Key instructions:**
- 0x01: PING - Check if servo responds
- 0x02: READ - Read register data
- 0x03: WRITE - Write register data
- 0x04: REG_WRITE - Buffered write
- 0x05: ACTION - Execute buffered writes
- 0x06: RESET - Reset to factory defaults
- 0x83: SYNC_WRITE - Write to multiple servos

**Key registers:**
| Address | Name | R/W | Description |
|---------|------|-----|-------------|
| 0x03 | ID | RW | Servo ID (1-253) |
| 0x04 | Baud Rate | RW | 0-7 (0=1Mbps) |
| 0x2A | Goal Position L | W | Target position low byte |
| 0x2B | Goal Position H | W | Target position high byte |
| 0x38 | Present Position L | R | Current position low byte |
| 0x39 | Present Position H | R | Current position high byte |
| 0x3C | Present Load L | R | Current load low byte |
| 0x3D | Present Load H | R | Current load high byte |

### Python Library

Use `feetech-servo-sdk` (installed via Poetry in Story 0.6):
```python
from scservo_sdk import *

# Initialize port
port = PortHandler('/dev/waveshare_ears')
port.openPort()
port.setBaudRate(1000000)

# Packet handler for SCS protocol
packet = PacketHandler(0)  # Protocol version 0 for SCS

# Ping servo
result, error = packet.ping(port, 1)  # Ping ID 1

# Read position
position, result, error = packet.read2ByteTxRx(port, 1, 0x38)

# Write position (move to center)
result, error = packet.write2ByteTxRx(port, 1, 0x2A, 512)
```
