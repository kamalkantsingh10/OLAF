### ESP32 Board: ESP32-S3-DevKitC-1 (N16R8)

Same board type as the Head module. Dual-core Xtensa LX7 @ 240MHz, 16MB flash, 8MB PSRAM.
- Dual-core: Core 0 = WiFi/OTA, Core 1 = real-time PID
- I2C0 (Wire): Master for BNO085 IMU (0x4A) + OLED (0x3C) on GPIO 4/5
- BNO085 INT on GPIO 6 (data-ready interrupt), RST on GPIO 7 (hardware reset)
- I2C1 (Wire1): Slave for Pi — GPIO 21=SDA, GPIO 47=SCL (J3 right header)

### I2C Register Map (Actual — from `i2c_slave.h`)

| Address | Name | R/W | Type | Description |
|---------|------|-----|------|-------------|
| 0x00 | STATUS | R | uint8 bitfield | Bit 0=BALANCING, Bit 1=MOTORS_ENABLED, Bit 7=ERROR |
| 0x01 | COMMAND | W | uint8 | 0x01=ENABLE_BALANCE, 0x02=DISABLE, 0x03=RESET, 0x04=CALIBRATE_IMU |
| 0x10 | LINEAR_VEL | W | float32 (4 bytes) | Target linear velocity (m/s) |
| 0x11 | ANGULAR_VEL | W | float32 (4 bytes) | Target angular velocity (rad/s) |
| 0x20 | ODOM_X | R | float32 (4 bytes) | Odometry X position (meters) |
| 0x21 | ODOM_Y | R | float32 (4 bytes) | Odometry Y position (meters) |
| 0x22 | ODOM_THETA | R | float32 (4 bytes) | Odometry heading (radians) |
| 0x30 | PITCH | R | float32 (4 bytes) | Current pitch angle (degrees) |
| 0x31 | BATTERY_VOLTAGE | R | float32 (4 bytes) | Battery voltage (volts) |

**Note:** Float values are transmitted as 4 raw bytes (little-endian IEEE 754) via `memcpy`. The ESP32 firmware handles differential drive splitting internally — the Pi sends linear/angular velocity, NOT per-wheel velocities.

### BNO085 IMU (On-Chip AHRS)

The BNO085 (GY-BNO085 breakout) replaces MPU6050/6500 with a major simplification: **on-chip Hillcrest SH-2 sensor fusion** outputs quaternions and euler angles directly. No complementary filter or Kalman filter needed on the ESP32.

```cpp
// BNO085 via Adafruit_BNO08x library
#include <Adafruit_BNO08x.h>

Adafruit_BNO08x bno08x;
sh2_SensorValue_t sensor_value;

// Enable rotation vector report at 200Hz (5000µs interval)
bno08x.enableReport(SH2_ROTATION_VECTOR, 5000);

// In loop — read euler angles directly from on-chip AHRS
if (bno08x.getSensorEvent(&sensor_value)) {
    // Quaternion to pitch extraction
    float qr = sensor_value.un.rotationVector.real;
    float qi = sensor_value.un.rotationVector.i;
    float qj = sensor_value.un.rotationVector.j;
    float qk = sensor_value.un.rotationVector.k;
    float pitch = asin(2.0f * (qr * qj - qk * qi)) * RAD_TO_DEG;
}

// Calibration save (call after calibration stabilizes)
sh2_saveDcdNow();

// Tare — set current orientation as zero reference
sh2_setTareNow(SH2_TARE_BASIS_ROTATION_VECTOR, SH2_TARE_AXIS_ALL);
```

- **I2C address:** 0x4A (default)
- **Library:** Adafruit_BNO08x (depends on Adafruit_BusIO)
- **Reports:** Rotation vector (most accurate), game rotation vector (no magnetometer, lower latency), gyro-integrated rotation vector (fastest)
- **Calibration:** BNO085 auto-calibrates accel/gyro when stationary. Magnetometer needs figure-8 motion. Save calibration to flash via `sh2_saveDcdNow()`. Restore on boot for fast startup. Use tare to zero pitch reference.

### PID Controller Notes

- **Use gyro rate directly for D-term** — cleaner than differentiating position (avoids derivative kick)
- **Anti-windup on I-term** — clamp integral to prevent windup when robot is held or fallen
- **Output = velocity (turns/sec)** sent to ODrive in velocity control mode
- **Setpoint is the balance angle** — typically ~0° but may need small offset depending on center of gravity
- **PID ranges** (from `balancing_controller.h` comments): Kp=20-35, Ki=0-0.2, Kd=5-8

### ODrive UART Protocol (ASCII)

```
v <axis> <velocity> <torque_ff>\n    # Set velocity (turns/sec)
f <axis>\n                            # Request feedback → pos vel
w axis<n>.requested_state <state>\n   # Set axis state (8 = CLOSED_LOOP)
```

### Coding Standards (C++ / ESP32)

From `docs/architecture/coding-standards.md`:
- **C++17**, modified Google style
- **Naming:** PascalCase classes, camelCase functions, snake_case variables, UPPER_SNAKE trailing_ privates
- **No dynamic allocation in loops** — pre-allocate all buffers
- **No `delay()` in loops** — use `millis()` non-blocking timing
- **Keep ISR handlers <10µs** — set flags only
- **Watchdog timer** on safety-critical code (2 sec timeout)
- **Serial logging** with `[INFO]`/`[WARN]`/`[ERROR]` prefixes
