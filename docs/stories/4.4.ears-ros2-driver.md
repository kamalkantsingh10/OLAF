# Story 4.4: Create Ears ROS2 Driver Node

## Status: Draft

## Story

**As a** builder,
**I want** ROS2 driver node for Ears module,
**so that** I can control ear expressions via ROS2.

## Acceptance Criteria

1. Python ROS2 node created in `ros2/src/olaf_ears/`
2. Node subscribes to `/ears/emote` (preset emotions) and `/ears/pose` (direct angles)
3. USB serial to second Waveshare adapter
4. Preset emotions: perked, relaxed, alert, sad, happy
5. Node launches and ears respond to topics

### Servo Configuration

| ID | Function | Neutral | Min | Max | Degrees/Count |
|----|----------|---------|-----|-----|---------------|
| 1 | Left base | 512 | 200 | 824 | ~0.29°/count |
| 2 | Left angle | 512 | 358 | 666 | ~0.29°/count |
| 3 | Right base | 512 | 200 | 824 | ~0.29°/count |
| 4 | Right angle | 512 | 358 | 666 | ~0.29°/count |

**Conversion formula:**
```python
def degrees_to_position(degrees, neutral=512, scale=3.41):
    """Convert degrees to servo position (10-bit).

    Args:
        degrees: Angle in degrees from neutral
        neutral: Center position (512)
        scale: Counts per degree (~3.41 for 300° range)

    Returns:
        Servo position (0-1023)
    """
    return int(neutral + degrees * scale)
```

| sad | -30 | -30 | -30 | -30 |
