# Story 0.4: Set Up Git Deployment Workflow

## Status: Draft

## Story

**As a** builder,
**I want** a git-based workflow for deploying code from PC to Pi,
**so that** I can develop locally and sync changes to the robot reliably.

## Acceptance Criteria

1. Git installed and configured on both PC and Pi
2. SSH key authentication set up for GitHub (passwordless push/pull)
3. OLAF repository cloned to `~/olaf/` on both machines
4. Deployment workflow documented and tested (push from PC, pull on Pi)
5. Colcon build succeeds after pull on Pi

## Tasks / Subtasks

- [ ] Task 1: Configure Git on PC (AC: 1)
  - [ ] Install git: `sudo apt install git`
  - [ ] Set user name: `git config --global user.name "Your Name"`
  - [ ] Set email: `git config --global user.email "your@email.com"`
- [ ] Task 2: Configure Git on Pi (AC: 1)
  - [ ] Install git: `sudo apt install git`
  - [ ] Set user name and email (same commands as PC)
- [ ] Task 3: Set up SSH keys for GitHub (AC: 2)
  - [ ] On PC: Generate key `ssh-keygen -t ed25519 -C "your@email.com"`
  - [ ] Add PC public key to GitHub account
  - [ ] On Pi: Generate key (same command)
  - [ ] Add Pi public key to GitHub account
  - [ ] Test: `ssh -T git@github.com` on both machines
- [ ] Task 4: Clone repo on PC (AC: 3)
  - [ ] Clone: `cd ~ && git clone https://github.com/kamalkantsingh10/OLAF.git olaf`
  - [ ] Verify structure: `ls ~/olaf/ros2/src`
- [ ] Task 5: Clone repo on Pi (AC: 3)
  - [ ] Clone: `cd ~ && git clone https://github.com/kamalkantsingh10/OLAF.git olaf`
  - [ ] Verify structure: `ls ~/olaf/ros2/src`
- [ ] Task 6: Test deployment workflow (AC: 4, 5)
  - [ ] On PC: Make small change, commit, push
  - [ ] On Pi: `cd ~/olaf && git pull`
  - [ ] On Pi: `cd ~/olaf/ros2 && colcon build`
  - [ ] Verify build succeeds
- [ ] Task 7: Document workflow
  - [ ] Verify `docs/guides/pc-development-setup.md` has deployment steps

## Dev Notes

### Workspace Structure (both machines)

Same simple structure on PC and Pi:

```
~/olaf/                          # Git repo (home base)
├── ros2/                        # ROS2 workspace
│   ├── src/                     # ROS2 packages
│   │   ├── olaf_head/
│   │   ├── olaf_base/
│   │   └── ...
│   ├── build/                   # Colcon output (gitignored)
│   ├── install/                 # Colcon output (gitignored)
│   └── log/                     # Colcon logs (gitignored)
├── modules/                     # ESP32 firmware
│   ├── head/
│   └── base/
└── docs/                        # Documentation
```

### Deployment Commands (Quick Reference)

**On PC (after editing):**
```bash
cd ~/olaf
git add .
git commit -m "feat: your change"
git push
```

**On Pi (to deploy):**
```bash
cd ~/olaf
git pull
cd ros2
colcon build
source install/setup.bash
```

### SSH Key Setup Notes
- Use Ed25519 keys (more secure, shorter)
- Add to GitHub: Settings → SSH and GPG keys → New SSH key
- Test with `ssh -T git@github.com`

### Testing

- **Test**: `git push` from PC succeeds
- **Test**: `git pull` on Pi gets latest changes
- **Test**: `colcon build` on Pi completes without errors
