# Story 4.2: Design Ear Mechanical Assembly

## Status: Draft

## Story

**As a** builder,
**I want** ear mechanical design with 2-DOF per ear,
**so that** ears can express emotions through movement.

## Acceptance Criteria

1. OnShape CAD model for ear mounts and ear shapes
2. 2 servos per ear: base rotation + ear angle
3. Ear shapes suitable for robot aesthetic
4. Mounting points on head enclosure
5. STL files exported and parts printed

## Tasks / Subtasks

- [ ] Task 1: Design ear base mounts (AC: 1, 2)
  - [ ] Create OnShape document for ear assembly
  - [ ] Design base bracket for SCS0009 servo (ID 1 left, ID 3 right)
  - [ ] Design servo horn adapter for second servo mounting
  - [ ] Ensure base rotation axis perpendicular to head surface
  - [ ] Add cable routing channels for servo wires

- [ ] Task 2: Design ear angle mechanism (AC: 2)
  - [ ] Design second servo (ID 2 left, ID 4 right) mounting bracket
  - [ ] Create linkage between servo and ear
  - [ ] Ensure ear angle axis allows forward/back tilt
  - [ ] Define motion range: ±45° from neutral

- [ ] Task 3: Design ear shapes (AC: 3)
  - [ ] Design ear shape appropriate for robot aesthetic (cat/fox/custom)
  - [ ] Size ears proportionally to head (approximately 60-80mm tall)
  - [ ] Design ear attachment point to servo horn

  - [ ] Design ear bracket flanges with screw holes

## Dev Notes

### Servo Specifications (SCS0009)

| Parameter | Value |
|-----------|-------|
| Dimensions | 23 × 12.2 × 29mm |
| Weight | 9g |
| Torque | 1.6 kg·cm @ 6V |
| Speed | 0.09 sec/60° @ 6V |
| Rotation | 300° (continuous optional) |
| Voltage | 4.8-7.4V |

### Ear Motion Requirements

| Motion | Servo | Range | Example Expressions |
|--------|-------|-------|---------------------|
| Base rotation | ID 1, 3 | ±60° | Perked (forward), Alert (sides), Relaxed (back) |
| Ear angle | ID 2, 4 | ±45° | Happy (up), Sad (down), Curious (tilted) |

### Expression Presets

| Expression | Base Rotation | Ear Angle | Description |
|------------|---------------|-----------|-------------|
| Neutral | 0° | 0° | Default resting position |
| Perked | +30° forward | +20° up | Alert, interested |
| Alert | +45° outward | 0° | Listening, scanning |
| Sad | -30° back | -30° down | Droopy, dejected |
| Happy | +20° forward | +30° up | Excited, joyful |
| Relaxed | -20° back | -10° down | Calm, resting |

### Design Guidelines

**Materials:**
- PLA or PETG for structural parts
- Consider flexible TPU for ear tips (optional)

**Print Settings (recommended):**
- Layer height: 0.2mm
- Infill: 20-30%
- Supports: Yes for overhangs >45°
- Walls: 3 perimeters

**Mechanical:**
- Use M2 or M2.5 screws for servo mounting
- Design for snap-fit where possible to reduce hardware
- Include clearance for wire routing
- Avoid tight tolerances (<0.2mm gap)
