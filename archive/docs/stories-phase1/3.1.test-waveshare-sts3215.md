## Dev Notes

### Hardware Configuration

**Waveshare Bus Servo Adapter (A):**
- USB mode (not standalone mode)
- Device: `/dev/waveshare_neck` (symlink via udev rule)
- Power input: 12V DC (from 36V→12V buck converter)

**Feetech STS3215 Servos:**
- Quantity: 3× (pan, tilt, roll)
- Protocol: STS (Serial bus) — uses `sms_sts` class in scservo_sdk
- Baud rate: 1000000 (1Mbps) default
- Position range: 0-4095 (12-bit)
- Rotation range: 360°
- Counts per degree: ~11.38 (4096 / 360)
- Voltage: 6-12.6V (using 12V)
- Torque: 30 kg·cm @ 12V
- Weight: 73g each

**Servo ID Assignments:**

| ID | Location | Function | Range |
|----|----------|----------|-------|
| 1 | Neck base | Pan (left/right) | ±90° |
| 2 | Neck middle | Tilt (up/down) | ±45° |
| 3 | Neck top | Roll (head tilt) | ±30° |

### STS3215 Protocol Differences from SCS0009

| Feature | SCS0009 (ears) | STS3215 (neck) |
|---------|---------------|----------------|
| Protocol class | `scscl` (protocol_end=1) | `sms_sts` |
| Position bits | 10-bit (0-1023) | 12-bit (0-4095) |
| Range | 300° | 360° |
| Counts/degree | ~3.41 | ~11.38 |
| Power | 4.8-7.4V | 6-12.6V |
| Torque | 1.6 kg·cm | 30 kg·cm |

### STS Protocol Key Registers

| Address | Name | R/W | Description |
|---------|------|-----|-------------|
| 0x05 | ID | RW | Servo ID (1-253) |
| 0x06 | Baud Rate | RW | Baud rate setting |
| 0x2A | Goal Position L | W | Target position low byte |
| 0x2B | Goal Position H | W | Target position high byte |
| 0x38 | Present Position L | R | Current position low byte |
| 0x39 | Present Position H | R | Current position high byte |
| 0x3C | Present Load L | R | Current load low byte |
| 0x3D | Present Load H | R | Current load high byte |
| 0x3E | Present Voltage | R | Current voltage |
| 0x3F | Present Temperature | R | Current temperature (°C) |

### Python Library

Use vendored `scservo_sdk` at `libs/scservo_sdk/` (pip version is stripped):
```python
from scservo_sdk import *

# Initialize port
port = PortHandler('/dev/waveshare_neck')
port.openPort()
port.setBaudRate(1000000)

# Use sms_sts for STS3215 (NOT scscl)
sts = sms_sts(port)

# Ping servo (lowercase method name)
result, error = sts.ping(1)

# Read position (returns 3-tuple)
position, result, error = sts.ReadPos(1)

# Write position with speed
sts.WritePosEx(1, 2048, 500, 50)  # ID, position, speed, acceleration
```

### Lessons from Ears (Story 4.1)

- pip `feetech-servo-sdk` is stripped — use vendored SDK at `libs/scservo_sdk/`
- Servo IDs persist in EEPROM through power cycles
- EEPROM offset register did NOT work on SCS0009 — use software center_position in config (may work differently on STS3215 but follow same software pattern for consistency)
- `set-center` saves raw positions to `config/servo-ids.yaml` — commit after calibration to avoid Pi-side git conflicts
