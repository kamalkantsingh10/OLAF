# Story 0.1: Install Ubuntu 24.04 and ROS2 Jazzy on Raspberry Pi

## Status: Draft

## Story

**As a** builder,
**I want** Ubuntu 24.04 LTS and ROS2 Jazzy installed on Raspberry Pi 5,
**so that** I can develop ROS2 driver nodes for OLAF modules.

## Acceptance Criteria

1. Ubuntu 24.04 LTS (64-bit) is installed on Pi 5 and boots successfully
2. ROS2 Jazzy Jalisco is installed following official installation guide
3. Core ROS2 packages are verified (`ros-jazzy-desktop` or `ros-jazzy-base`)
4. `rosdep` is initialized and dependencies are installed
5. ROS2 environment is sourced in `.bashrc` for automatic activation
6. Basic ROS2 commands work: `ros2 topic list`, `ros2 node list`

## Tasks / Subtasks

- [ ] Task 1: Install Ubuntu 24.04 LTS on Pi 5 (AC: 1)
  - [ ] Download Ubuntu 24.04 LTS (64-bit) image for Raspberry Pi
  - [ ] Flash image to SD card using Raspberry Pi Imager
  - [ ] Boot Pi 5 and complete initial setup (user, locale, network)
  - [ ] Verify system boots and network connectivity works
- [ ] Task 2: Install ROS2 Jazzy Jalisco (AC: 2, 3)
  - [ ] Add ROS2 apt repository and GPG key
  - [ ] Update apt and install `ros-jazzy-desktop` (or `ros-jazzy-base`)
  - [ ] Verify installation with `ros2 --version`
- [ ] Task 3: Initialize rosdep (AC: 4)
  - [ ] Run `sudo rosdep init`
  - [ ] Run `rosdep update`
- [ ] Task 4: Configure environment (AC: 5, 6)
  - [ ] Add `source /opt/ros/jazzy/setup.bash` to `~/.bashrc`
  - [ ] Source bashrc or restart terminal
  - [ ] Verify `ros2 topic list` and `ros2 node list` work

## Dev Notes

### Tech Stack Reference
- **OS**: Ubuntu 24.04 LTS (64-bit) - Native ROS2 Jazzy support
- **ROS2**: Jazzy Jalisco (LTS until 2029)
- **Hardware**: Raspberry Pi 5 16GB

### Installation Resources
- ROS2 Jazzy installation: https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html
- Ubuntu 24.04 for Pi: https://ubuntu.com/download/raspberry-pi

### Testing

- **Test**: Run `ros2 topic list` - should return empty list without errors
- **Test**: Run `ros2 node list` - should return empty list without errors
- **Test**: Run `ros2 run demo_nodes_cpp talker` in one terminal, `ros2 run demo_nodes_cpp listener` in another - should see messages
