### Servo Configuration

| ID | Function | Neutral | Min | Max | Degrees/Count |
|----|----------|---------|-----|-----|---------------|
| 1 | Left base | 512 | 200 | 824 | ~0.29°/count |
| 2 | Left angle | 512 | 358 | 666 | ~0.29°/count |
| 3 | Right base | 512 | 200 | 824 | ~0.29°/count |
| 4 | Right angle | 512 | 358 | 666 | ~0.29°/count |

**Conversion formula:**
```python
def degrees_to_position(degrees, neutral=512, scale=3.41):
    """Convert degrees to servo position (10-bit).

    Args:
        degrees: Angle in degrees from neutral
        neutral: Center position (512)
        scale: Counts per degree (~3.41 for 300° range)

    Returns:
        Servo position (0-1023)
    """
    return int(neutral + degrees * scale)
```
