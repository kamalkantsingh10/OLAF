# Story 0.7: Set Up Development Tools on PC

## Status: Draft

## Story

**As a** builder,
**I want** all development tools installed on my PC,
**so that** I can efficiently develop ROS2 nodes and ESP32 firmware.

## Acceptance Criteria

1. Python 3.11+ available with virtual environment support
2. PlatformIO installed for ESP32 firmware development
3. VS Code installed with ROS2 and PlatformIO extensions
4. Required Python packages installed: `smbus2`, `pyserial`, `numpy`, `colcon-common-extensions`
5. USB permissions configured for ESP32 flashing
6. Colcon build tools installed for ROS2 workspace builds

## Tasks / Subtasks

- [ ] Task 1: Verify Python version (AC: 1)
  - [ ] Run `python3 --version` - should be 3.11+
  - [ ] Install venv if needed: `sudo apt install python3-venv`
- [ ] Task 2: Install VS Code (AC: 3)
  - [ ] Download from https://code.visualstudio.com/ or `sudo snap install code --classic`
  - [ ] Launch and verify working
- [ ] Task 3: Install VS Code extensions (AC: 3)
  - [ ] Install "ROS" extension (by Microsoft)
  - [ ] Install "PlatformIO IDE" extension
  - [ ] Install "Python" extension (by Microsoft)
  - [ ] Install "C/C++" extension (for firmware editing)
- [ ] Task 4: Install PlatformIO CLI (AC: 2)
  - [ ] Run `pip install platformio`
  - [ ] Verify: `pio --version`
  - [ ] Install udev rules for ESP32:
    ```bash
    curl -fsSL https://raw.githubusercontent.com/platformio/platformio-core/develop/platformio/assets/system/99-platformio-udev.rules | sudo tee /etc/udev/rules.d/99-platformio-udev.rules
    sudo udevadm control --reload-rules && sudo udevadm trigger
    ```
- [ ] Task 5: Configure USB permissions (AC: 5)
  - [ ] Add user to dialout group: `sudo usermod -aG dialout $USER`
  - [ ] Log out and back in
  - [ ] Test ESP32 detection when connected
- [ ] Task 6: Install Python dependencies (AC: 4)
  - [ ] Run `pip install smbus2 pyserial numpy`
  - [ ] Verify imports work
- [ ] Task 7: Install colcon build tools (AC: 6)
  - [ ] Run `sudo apt install python3-colcon-common-extensions`
  - [ ] Verify: `colcon --help`
- [ ] Task 8: Test ESP32 flashing (AC: 2, 5)
  - [ ] Connect ESP32 via USB
  - [ ] Run `pio device list` - should show device
  - [ ] Create test project or flash existing firmware

## Dev Notes

### Tech Stack Reference (from docs/architecture/tech-stack.md)
- **Orchestrator Language**: Python 3.11+
- **Module Firmware Language**: C/C++ (C++17) for ESP32
- **Build Tool (Firmware)**: PlatformIO 6.1+
- **Build Tool (Orchestrator)**: colcon (ROS2 standard)
- **Testing Framework (Python)**: pytest 7.4+

### ESP32 Module Configuration
- **MCU**: ESP32-S3-DevKitC-1 (ESP32-S3-WROOM-2, N16R8)
- **Firmware Location**: `modules/{module}/firmware/`
- 16MB flash, 8MB PSRAM

### VS Code Recommended Settings
Add to `.vscode/settings.json` in workspace:
```json
{
  "python.linting.enabled": true,
  "python.linting.pylintEnabled": true,
  "editor.formatOnSave": true,
  "files.trimTrailingWhitespace": true
}
```

### Why These Tools?
- **PlatformIO**: Superior to Arduino IDE for ESP32 development
- **VS Code**: Best cross-platform IDE with ROS2 + PlatformIO integration
- **colcon**: Standard ROS2 build system

### Testing

- **Test**: `python3 --version` shows 3.11+
- **Test**: `pio --version` runs successfully
- **Test**: `colcon --help` shows help text
- **Test**: ESP32 flashes without permission errors
